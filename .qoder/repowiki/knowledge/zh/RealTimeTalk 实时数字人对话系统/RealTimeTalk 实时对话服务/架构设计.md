server/main.py 通过 lifespan 钩子在进程启动时集中初始化 Redis、MinIO、Qdrant、Embedding 等全局单例，并把它们注入到 agent_engine、knowledge_routes 以及 WebSocket 处理器中；各子模块按职责分层：
- api/* 仅负责 HTTP/WebSocket 路由与协议编解码，不持有业务状态；
- agent/* 承载会话编排与对话逻辑，依赖 services 层提供的 LLM/TTS/RAG 能力；
- pipeline/* 实现音频分段与流式拼接，由 AgentEngine 在会话生命周期内调度；
- services/* 是对外部系统（LLM、TTS、Redis、MinIO、Qdrant、FFmpeg）的统一封装，被 agent 和 api 共同消费；
- models/* 定义 SessionContext、Message 等跨层共享的数据契约。
配置通过 config.get_config() 懒加载，JSON 文件与 .env 环境变量合并后以扁平 dict 形式供所有子模块读取，形成“入口装配 → 全局单例 → 子模块消费”的单向依赖链。
