- 组件间通过 `ref` 暴露命令式 API（如 `AvatarViewHandle.play/playLoop`），而非通过 props 传递回调，保持 UI 组件的声明式风格。
- WebSocket 相关状态使用 `useRef` 保存最新值并在 `useEffect` 中同步到 ref，避免闭包捕获过时 state 导致竞态。
- 服务端事件在 `App.handleWsEvent` 中以 `switch (event.type)` 分派，新增事件类型需在此处显式处理，禁止在组件内直接解析原始消息。
- HTTP 调用统一经 `services/api.ts` 的泛型 `request<T>` 函数封装，错误时抛出带 HTTP 状态码的 Error，组件侧只消费 Promise 结果。
- 长生命周期副作用（定时器、事件监听）在 `useEffect` 返回的清理函数中释放，防止组件卸载后仍触发回调。
