本模块为纯 Markdown 文档集合，按职责拆分为：
- `tech-spec.md`：端到端技术设计总纲，覆盖系统分层（React/Vite 前端 + FastAPI WebSocket + Agent/StreamingPipeline + Redis/MinIO）、会话隔离、WebSocket 事件协议、Docker Compose 编排及错误处理策略。
- `req-spec.md` / `req-raw.md`：原始需求与规范化需求描述。
- `test-spec.md`：测试范围与用例约定。
- `Qdrant知识库操作指南.md`：面向运维的 Qdrant collection 管理步骤。
- `deploy-manual.md`：面向阿里云 ECS ARM64 节点的 Docker Swarm 发布流程，包含镜像构建、Stack 部署、nginx-gateway 增量配置、SSL 证书申请与回滚方案。
各文档通过交叉引用（如 tech-spec 顶部标注对应 req-spec）形成单一事实源，不依赖任何构建脚本或外部工具。
