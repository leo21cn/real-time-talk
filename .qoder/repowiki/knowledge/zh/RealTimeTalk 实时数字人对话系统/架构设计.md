根目录作为编排层，将三个子模块按运行时角色组合：
- server 通过 `server/main.py` 启动 FastAPI 应用，注册 `api/` 下的 REST 路由与 WebSocket 处理器，内部由 `agent/`（会话与 Agent 引擎）、`pipeline/`（语义分段+流式生成）、`rag/`（Qdrant 检索）和 `services/`（LLM/TTS/MinIO/Redis 客户端）协作完成一次对话；
- client 经 Vite 构建后由同一 FastAPI 静态文件服务或 Nginx 反向代理分发，前端通过 `useWebSocket` hook 订阅服务端事件并驱动 AvatarView 播放 clips 资源；
- 顶层 `Dockerfile` + `docker-compose.yml` / `docker-stack.yml` 将 server、Nginx、以及外部依赖（Qdrant、MinIO、Redis）打包为可部署单元，`nginx.conf` / `nginx-pulan.conf` 负责 `/api` 转发到 FastAPI、静态资源走本地或 CDN。
跨子模块的契约集中在 `server/models/`（Message/SemanticLabel/Session 等 Pydantic 模型）与 `client/src/types/`（chat.ts/events.ts），前后端共享同一套事件协议，WebSocket 是唯一的实时通道。
