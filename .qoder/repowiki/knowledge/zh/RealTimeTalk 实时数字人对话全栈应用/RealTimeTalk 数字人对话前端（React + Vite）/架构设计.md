模块采用双入口 SPA 架构：`index.html` → `src/main.tsx` → `App` 组件构成主聊天页面，`admin.html` → `src/admin.tsx` → `AdminPage` 构成知识库管理后台；Vite 通过 `vite.config.ts` 的 `rollupOptions.input` 同时打包这两个入口。

内部按职责分层、依赖方向单向：
- `components/`：纯 UI 展示组件（AvatarView、ChatPanel、ChatBubble、InputBox、SpeechBubble、ErrorBubble、KnowledgePanel、AdminPage），无业务状态，仅接收 props 并通过 ref 暴露命令式 API（如 `AvatarViewHandle.play/playLoop`）。
- `hooks/`：封装跨组件复用的副作用逻辑，`useWebSocket` 集中处理连接建立、token 获取/持久化、指数退避重连与消息收发；`useTypewriter` 用于打字机效果。
- `services/api.ts`：REST 层，统一以 `/api` 前缀发起 fetch 请求，封装 create/get/destroy session 三个接口。
- `types/`：共享类型定义，`events.ts` 描述客户端/服务端 JSON 协议，`chat.ts` 描述本地消息模型。
- `App.tsx` 作为根容器持有全局状态机（Idle / Thinking / Speaking / Bridging），通过 `useWebSocket` 订阅 `ServerEvent`，根据事件类型切换状态、追加消息、驱动 AvatarView 播放对应视频片段，并在段末发送 `ack_played`。
