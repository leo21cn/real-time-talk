本模块是 RealTimeTalk 服务的进程级入口，由两个文件组成：
- `main.py`：定义 FastAPI 实例并通过 `lifespan` 协程完成启动期资源装配（Redis → MinIO → Qdrant → Embedding），注册 `server.api.*` 下的 REST 路由与 `/ws` WebSocket 端点，并在关闭阶段取消活跃 Pipeline、清理 `sessions` 字典并断开外部连接；同时以 `StaticFiles` 挂载 `static/` 目录实现 SPA 回退。
- `config.py`：使用 `pydantic_settings.BaseSettings` 声明所有可环境变量覆盖的配置项（`AppConfig`），并提供 `load_config()` 将 `config.json` 与 `.env` 合并为扁平的嵌套 dict，暴露 `get_config()` / `reload_config()` 作为全局懒加载单例。
依赖方向单向向外：本模块仅被顶层脚本调用，反向被 `server/api/*`、`server/services/*`、`server/models/session.py` 等子包通过 `from server.config import get_config` 读取配置，自身不依赖业务逻辑层。
