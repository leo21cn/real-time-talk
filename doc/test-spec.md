## 1. 测试概述

### 1.1 测试范围

| 类别 | 覆盖内容 |
|------|----------|
| REST API | 5 个端点：Session CRUD、Clips 代理、Media 代理 |
| WebSocket 协议 | 连接/断开、8 种服务端事件、3 种客户端消息 |
| 前端状态机 | Idle → Input → Thinking → Speaking/Bridging → Idle |
| 流式分段引擎 | 分段策略、并行生成、确认式推送、中断处理 |
| 会话隔离 | 多 Session 独立上下文、Token 生命周期、Redis 持久化 |
| 异常处理 | LLM/TTS/FFmpeg/MinIO/Redis/WebSocket 故障 |
| 输入校验 | 空消息、超长输入、特殊字符 |
| 非功能需求 | 首字延迟、分段衔接、断线重连、配置优先级 |

### 1.2 测试环境约定

| 项目 | 说明 |
|------|------|
| 测试地址 | `http://localhost:80`（Nginx 代理） |
| 直接后端 | `http://localhost:8000`（FastAPI） |
| WebSocket | `ws://localhost:80/ws` 或 `ws://localhost:8000/ws` |
| 外部 API 模拟 | LLM / TTS 使用 Mock Server 替代真实 API |
| Redis | `redis://localhost:6379/0` |
| MinIO | `localhost:9000`，bucket `realtimetalk` |

### 1.3 测试数据说明

所有测试用例使用统一的测试数据集（参见 §9），包括：
- 短回复文本（≤50 字）
- 长回复文本（>50 字，触发多段）
- 各种语义标签触发文本
- 边界值输入（空、2000 字、特殊字符）
